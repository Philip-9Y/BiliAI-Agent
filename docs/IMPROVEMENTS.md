## 2026-11-26：交付级加固

### 0. 视频追溯状态可见 + 桌面客户端剪贴板兜底

**场景**：用 B站桌面客户端看视频，截图后不知道有没有拿到视频 URL/BV。

**以前**：浏览器扩展只有网页能用；桌面客户端只拿到窗口标题，界面上也看不出来。

**现在**：

- 运行状态显示视频追溯来源：浏览器扩展 / 剪贴板链接 / 仅窗口标题 / 无
- 桌面客户端先复制视频链接或 BV，再截图提问，App 会从剪贴板读取
- 有链接时 Agent 可调用 `get_bilibili_video` 获取标题、UP主、时长、分P

**限制**：桌面客户端本身仍不能被扩展注入；必须手动复制链接，或改用浏览器网页。

### 0. 回答上方新增“运行状态”

**场景**：截屏提问后，不知道有没有走云端、有没有检索记忆、有没有调用工具。

**以前**：只有最终答案；没有工具调用时看不到任何过程。

**现在**：每条新回答上方显示：

```text
模型路由：云端视觉模型 · 截图
记忆检索：命中 0 条
完成：云端视觉模型 · 截图 · 11.1s · 工具 0 次
```

- 有工具时继续显示工具卡片
- 运行信息持久化到消息 meta，历史会话也能看到
- 流式回答也记录路由/耗时/工具数

**限制**：本次修改前的历史回答没有旧运行信息。

### 0.1 桌面快捷方式打不开/窗口不出来

**场景**：App 已经运行，但主窗口隐藏到托盘；再点桌面快捷方式没有反应。

**原因**：

- 新启动的进程发现已有实例，会通过本地 socket 发送 `show`；
- 原进程有时在 `readyRead` 信号连接之前就已经收到数据；
- 信号不再触发，`show` 被丢掉，窗口一直隐藏。

**现在**：

- 连接建立后立即补一次缓冲读取；
- 用 50ms 定时器再兜底读一次；
- 隐藏到托盘后，点快捷方式/再次启动可以恢复主窗口。

**验证**：

```text
主窗口 visible=True
关闭到托盘 visible=False
启动桌面快捷方式 visible=True
```

**如果仍然打不开**：

1. 双击桌宠；
2. 按 `Ctrl+Alt+H`；
3. 或右键托盘图标 → 打开主界面；
4. 仍无反应时，任务管理器结束 `pythonw.exe`，再启动。

### 1. 热键冲突

**场景**：按 `Ctrl+Alt+X` 想退出，但被其他软件占用。

**以前**：日志报错，退出热键不可用；更早版本还会导致后续热键全部失效。

**现在**：

- 退出改为 `Ctrl+Alt+Shift+X`
- 对话改为 `Ctrl+Alt+Shift+A`
- 任一原热键失败时，自动尝试加 `Shift` 的备用键
- 一个键失败不会注销其他热键
- 托盘会提示“已自动切换”

**验证**：启动日志出现“全局热键注册成功”。

**限制**：如果原键和 Shift 键都被占用，该功能仍需用托盘/按钮。

### 2. 自检 `--check`

**场景**：安装后不确定数据库、模型、Ollama、扩展、端口、热键是否正常。

**以前**：`--check` 会启动完整 Qt 界面，窗口版没有 stdout，容易卡住/退出码不稳定。

**现在**：

```powershell
python app.py --check
```

- 不启动 Qt、不弹窗
- 检查 SQLite、配置、API Key、BGE 模型、扩展、8765 端口、Ollama、全部热键
- 结果写入 `data/selfcheck.json`
- 核心通过返回 0；热键被占用只记 warning
- 安装后的 `Study-AI.exe --check` 也已验证

**限制**：App 正在运行时，端口/热键检查会报“被占用”，这是正常现象。

### 3. 插件沙箱

**场景**：从网络安装了一个插件，担心它把主程序搞崩、读环境变量、卡死界面。

**以前**：插件直接 `import` 到主进程，拥有和 App 一样的权限。

**现在**：

- 每个插件在独立子进程运行
- 主进程只通过 JSON RPC 调用
- 单次调用默认 12 秒超时，超时杀进程
- 子进程清除 API Key/Token 等环境变量
- 工作目录固定为插件目录
- 插件崩溃不会带崩主界面

**怎么用**：插件管理里安装/启用，调用方式不变。

**限制**：这是**进程沙箱**，不是 Windows 内核沙箱；插件仍可能读写本机文件/访问网络。不要安装不可信插件。

### 4. ANN 记忆候选

**场景**：长期记忆从几十条涨到几百/几千条，每次问答都全量算余弦，变慢。

**以前**：所有记忆线性比较。

**现在**：

- 少于 `ann_threshold`（默认 128）条：线性精确检索
- 超过阈值：随机超平面 LSH 取候选，再做精确余弦
- Top-5 改用 `heapq.nlargest`，不再完整排序
- 移除了 LSH 候选的任意切片截断
- 关键词命中仍独立保留

**配置**：`ann_threshold`、`ann_bits`、`ann_tables`。

**限制**：LSH 是近似算法，可能漏召回；目前没有 recall 指标，也没有 HNSW/多探测。

### 5. 代码签名

**场景**：Windows 安装包提示“未知发布者”。

**现在**：

- 新增签名脚本 `scripts/sign_windows.ps1`
- 已用开发自签名证书签名 exe / 沙箱 worker / 安装包

**限制**：自签名证书不受 Windows 信任，SmartScreen 仍会提示。正式分发必须购买受信任的 OV/EV 代码签名证书。

## 2026-11-26：P0 工程能力

### 7. 浏览器扩展 / 本地桥

**场景**：看 B 站时，App 只知道窗口标题，不知道 URL、进度、字幕。

**以前**：靠标题猜视频，B 站接口 412 时无法拿信息。

**现在**：

- Chrome/Edge 扩展读取 URL、标题、播放进度、字幕、选中文字
- 每 2 秒 POST 到 `127.0.0.1:8765`
- App 只采用最近 20 秒数据
- 截图/文字提问时自动拼进上下文

**怎么用**：`chrome://extensions` → 开发者模式 → 加载 `extension/`。

**限制**：字幕选择器依赖 B 站 DOM，改版可能失效；桥没有鉴权，只适合本机。

---

### 8. 流式回答

**场景**：简单问题等半天才出字。

**以前**：所有回答等 Agent 完整跑完。

**现在**：

- 简单纯文字问答：本地/云端逐字显示
- 截图、工具、复杂任务：仍走原 Agent 工具循环，最后一次渲染

**限制**：工具调用阶段不是流式；截图问答仍云端。

---

### 9. 网络重试

**场景**：DeepSeek 偶发 429/5xx/连接失败。

**以前**：直接报错。

**现在**：

- 429/500/502/503/504/网络错误自动重试
- 指数退避，尊重 `Retry-After`
- 默认重试 2 次
- 400/401 不重试

**限制**：超时重试可能造成重复生成/重复计费；没有幂等键和熔断。

---

### 10. 指标与评测

**场景**：改完不知道变好还是变坏。

**现在**：

- `data/metrics.jsonl` 记录每次运行的耗时、路由、工具数、字符数、是否流式
- `eval/tasks.json` + `scripts/eval_tasks.py` 做任务级评测

**限制**：指标还比较基础，没有 recall@k、用户满意度、token 成本曲线。

---

### 11. 安装包

**场景**：换电脑或给同学用，不能每次装 Python。

**现在**：

- PyInstaller onedir + Inno Setup
- 安装包包含 models、extension、sandbox worker
- 首次启动在 exe 同目录生成 config/data

**限制**：安装包约 311MB；未在干净机器上做完整安装/卸载冒烟测试。

## 2026-11-26：模型与记忆

### 12. 本地/云端自动路由

**场景**：简单问题不想花云端 token。

**以前**：所有问题云端。

**现在**：

- 自动：简单文字本地，截图/工具/复杂云端
- 本地优先：简单文字本地，其余云端
- 仅云端
- 顶部可手动切换模式、本地模型、云端模型
- 本地失败自动回退云端

**限制**：路由是规则判断，短但复杂的任务可能误走本地。

---

### 13. BGE 语义记忆

**场景**：关键词对不上，但意思相近，召不回记忆。

**现在**：

- `BAAI/bge-small-zh-v1.5` 本地 512 维向量
- 关键词 + 字符 + 语义混合
- 模型缺失自动回退关键词

**限制**：权重手工设定，相似度阈值近似，没有 rerank。

---

### 14. 模糊追问改写

**场景**：“这个为什么”“刚才那步”这种追问，记忆检索不知道指什么。

**现在**：

- 最近几轮问题 + 当前追问 → 改写成完整检索问题
- 只影响记忆检索，不改变回答主流程
- 失败自动用原问题

**限制**：只对短/含指代的问题触发；改写模型可能改写偏。

---

### 15. 自动记忆

**场景**：聊过的重要内容，过几天忘了。

**现在**：

- 每 6 条消息后台整理一次
- 可手动编辑/删除/停用
- 自动注入相关记忆

**限制**：靠 LLM 抽取，可能漏/重复/过时；没有来源置信度 UI。

---

### 16. 长对话摘要

**场景**：聊太久，上下文超限/变慢。

**现在**：

- 超过字符阈值后压缩旧消息
- 保留最近 12 条
- 摘要存数据库，下次复用

**限制**：按字符不按 token；可能丢公式/约束；摘要可能幻觉。
