## 2026-11-26：交付级加固

| 改动 | 作用 |
| --- | --- |
| 退出热键改为 `Ctrl+Alt+Shift+X` | 避开被占用的 `Ctrl+Alt+X` |
| 对话热键改为 `Ctrl+Alt+Shift+A`，并支持 Shift 自动备用 | 热键冲突时仍能唤起 |
| `--check` 改为无 GUI 自检 | 不启动 Qt，结果写 `data/selfcheck.json`，返回码稳定 |
| 用户插件进程沙箱 | 独立子进程、JSON RPC、超时、环境变量清理 |
| 沙箱 worker 独立打包 | 窗口版主程序没有 stdout，必须用 console worker |
| ANN（随机超平面 LSH） | 记忆超过阈值后候选召回，再做精确余弦 |
| 代码签名脚本 | 支持 PFX/证书指纹/开发自签名 |
| 开发自签名已执行 | exe/sandbox/安装包已签名；证书链不受信任，仅开发验证 |
| 文档新增算法说明 | 区分贪心、DP、分治、回溯、LSH 等 |
| 清理旧代码/构建产物 | 删除约 2200 行死代码和 2.5GB 中间产物 |
